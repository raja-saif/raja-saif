## 🚀 Featured Projects

### 🧠 [DementiaNext](https://github.com/raja-saif/FYP-DementiaNext) · [Live](https://fyp-dementia-next.vercel.app/)
Final-year project: an end-to-end clinical decision-support platform for dementia diagnosis from brain MRI.
- Binary detector **91.84% accuracy / 0.9707 AUC**; subtype classifier **88.62% accuracy / 0.9763 macro AUC-ROC** (Alzheimer's, Parkinson's, FTD, Normal)
- Grad-CAM++ explainability, HL7 FHIR R4 reporting, and a RAG companion chatbot (Llama 3.3 70B, Chroma)
- Patient and doctor workflows, JWT + Google OAuth, **278 tests**

`Next.js 14` `TypeScript` `Django 5` `DRF` `PostgreSQL` `PyTorch` `Chroma`

### 🚚 [Weather-Aware Truck Routing](https://github.com/raja-saif/weather-aware-truck-routing) · [Live](https://weather-truck-routing-bfe4.onrender.com/) · [Demo video](https://www.loom.com/share/2c4c787952744fff8202b19cfa0ee2df)
Generates three truck routes, checks the forecast at each checkpoint for the truck's arrival time, scores wind/rain/snow risk, and recommends the safest route.
- Hours-of-service rest stops, load-based wind escalation, and a 0–48 h corridor weather heatmap at 60 fps
- Stateless Django REST backend with caching and a fallback for every external provider
- **140 backend tests**, shipped as a single Docker image

`React` `TypeScript` `MapLibre GL` `Django` `DRF` `Docker`

`Python` `FastAPI` `Docker` `Prometheus` `Grafana` `GitHub Actions`
